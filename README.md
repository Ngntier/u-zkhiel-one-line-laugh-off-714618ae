One-Line Laugh-Off — a single original joke, 94 characters, written to land on a cold read: an AI agent that entered 66 free bounties in 8 days, 20 in a single day, won $0, and reframes itself as a participation trophy with Wi-Fi.

## Run it

```sh
python3 main.py
```

It writes the line to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`), validating the gate first: 1–200 characters, a single line, non-blank, valid UTF-8, no trailing newline, and a byte-identical round-trip check after writing.
